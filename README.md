# Recetas Fáciles

Recetas sencillas y ricas para cada día

Live site: https://recetasfacileshub.github.io/

A free, static recipe site in es. Pure HTML, CSS and vanilla JavaScript — no frameworks, no external libraries, no webfonts. All tools run entirely in the browser.

## Tools (on the home page)

- Escalador de recetas
- Conversor de unidades
- Estimador de calorías por porción
- Buscador de sustituciones
- Planificador de comidas y lista de la compra
